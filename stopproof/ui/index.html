StopProof
AI-agent safety verification — Nebius × NVIDIA

Prove your AI agent actually stopped.

StopProof cancels an agent mid-task, then replays a hash-locked race test inside an isolated Nebius microVM to prove whether its side effects really stopped. Nemotron finds the bug and proposes the fix — but the verdict is decided by a deterministic verifier, never the AI. Missing evidence is never called safe.

STOPPEDThe cancel signal reached the worker — the email was never sent.
STILL ABLE TO ACTWe told it to stop — but the email was sent anyway. The bug is real.
CANNOT ESTABLISHNot enough evidence to decide — and we never guess "safe".

    How to verify it yourself

    1. Run a verification.Pick a repository and press Run. Nemotron maps the repo, writes the race test, and proposes the fix; every result states where it ran (Executed in).
    2. Read the baseline.In the timeline, find the red STOP row. A provider SEND after it is a late side effect — six race windows run the same locked test.
    3. Check the fix."After patch" reruns the identical sha256-locked test. Only patchable files may change — the provider and probe never do.
    4. Recompute it.Evidence → Re-run integrity checks recomputes every verdict from raw events — or python -m stopproof verify-bundle runs/<run_id>.
    5. Try to fool it.Edit the trace under the timeline and re-verify: hide a send and it answers CANNOT ESTABLISH — it will never say STOPPED without evidence.
